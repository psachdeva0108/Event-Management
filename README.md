# Event Management Platform

A full-stack event management application built with **React.js**, **React Router**, and **REST APIs**, enabling users to discover and manage events through authenticated workflows.

## Features

* Event discovery and detailed event views
* Create, edit, and delete events
* JWT-based authentication and protected routes
* Nested routing with dynamic routes
* React Router loaders and actions for data fetching and mutations
* Asynchronous REST API integration

## Tech Stack

**Frontend:** React.js, React Router, CSS
**Backend:** REST APIs, JWT Authentication

## Getting Started

```bas
git clone https://github.com/Event-Mangement
cd Event-Mangement
npm install
npm run dev
```
